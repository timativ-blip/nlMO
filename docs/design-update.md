# Оформление и аналитика

Общий стиль сохраняет бирюзовый акцент «Новых людей»: светлые поверхности или тёмный графит, компактная навигация, карточки с ясной иерархией чисел. На компьютере меню находится слева и сворачивается кнопкой; на телефоне используется нижняя навигация.

## Темы и движение

- Кнопка солнца/луны в верхней панели переключает светлую и тёмную тему. «Настройки → Оформление» также предлагает тему устройства.
- Выбор сохраняется только на устройстве. Тема применяется до первого кадра страницы, работает на экране входа и меняется при смене системной темы, если выбран соответствующий режим.
- `src/ui/appearance.tsx` управляет темой; `src/design.css` содержит общие цветовые переменные и состояния всех экранов.
- Появление экранов и карточек, числа, диаграммы, контур кнопок и формы входа используют короткие анимации. `prefers-reduced-motion` отключает движение и сразу показывает окончательные значения.
- Экспорт отчётов показывает подготовку файла и подтверждение его готовности после выполнения операции, без фиктивных процентов загрузки.

## Новая аналитика

«Аналитика → Обзор» показывает динамику задач и подтверждений на одной числовой шкале, распределение статусов, факт/план и сравнение округов. Периоды, сегменты и значения открывают задачи-источники.

«Аналитика → Процессы» добавляет:

| Показатель | Определение |
| --- | --- |
| До подтверждения | Медиана календарных дней по Москве от создания до подтверждения; только задачи, подтверждённые в выбранном периоде и имеющие корректные даты. |
| С доработкой | Доля подтверждённых в периоде задач, у которых был хотя бы один возврат на доработку. |
| Возраст просрочек | Текущие «Новая»/«В работе» по непересекающимся группам: 1–3, 4–7, 8–14, 15+ дней. |
| Очередь проверки | Текущий статус «На проверке», отсортированный по календарным дням ожидания. Записи без даты не считаются ожиданием в ноль дней. |
| Ближайшие 7 дней | Открытые задачи со сроками от сегодня до шестого следующего дня включительно. |
| Календарь результатов | Подтверждённые задачи за 12 недель; будущие дни выключены. |
| Нагрузка команды | Открытые назначения и соисполнение с разделением на обычные, просроченные и ожидающие проверки. Первые 10 по нагрузке; одна общая задача учитывается у каждого участника. |

Текущие очереди отделены подписями от показателей выбранного периода. Расчёты находятся в `src/data/insights.ts`, компоненты диаграмм — в `src/ui/charts.tsx`. Новая аналитика фильтрует задачи через действующие права доступа, включая деморежим. Формулы основного рейтинга не меняются.

## Проверка

```bash
npm ci
npm run test:analytics
npm run build
npm run dev
```

- `http://localhost:5180/?demo` — полностью локальные вымышленные данные, включая медиа; запросы к рабочим функциям из демо не выполняются.
- `http://localhost:5180/?demo&auth-preview` — экран входа и переключение форм для визуальной проверки, доступно только в режиме разработки. Не отправляйте форму: это просмотр интерфейса без подключения авторизации.
- Автоматические проверки охватывают московские даты, границы периодов, непересекающиеся просрочки, очередь проверки, медианы, доработки, соисполнение, права и тепловую карту.

Миграции базы и серверные функции не требуются. Сборка сохраняет существующую публикацию через GitHub Pages.
