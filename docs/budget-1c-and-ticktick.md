## Бюджет и подготовка загрузки в 1С

В разделе «Штаб → Бюджет» у каждого округа и медиа появляется отдельный бюджет с нулевой исходной суммой. Руководитель, заместитель руководителя и разработчик меняют лимиты и могут добавить направления с ответственным сотрудником. Координатор и заместитель координатора подают заявки по своему округу. Медиа-штаб подаёт заявки по бюджету медиа.

Отметка «Деньги отправлены» создаёт выдачу и уменьшает сумму, доступную к выдаче. Это запись о фактическом переводе. Получатель добавляет расходы с чеками. Руководство принимает их или возвращает с комментарием.

«Архив для 1С» содержит файл UTF-8 `expenses.json` и оригиналы выбранных принятых чеков в `receipts/`. Версия формата — `schemaVersion: 1`, валюта — `RUB`, суммы — целые копейки. У бюджета, выдачи и расходов есть стабильные `externalId`. По ним обработка 1С может распознавать повторный импорт. Для каждого расхода указаны дата, назначение, сумма, дата приёмки и путь к файлу внутри архива.

Для автоматической загрузки необходимы название и версия вашей конфигурации 1С, тип документа для этих расходов, правила поиска получателя и округа в справочниках, место хранения чеков и тестовая база. Архив представляет формат обмена сайта. Соответствие реквизитам 1С и создание документов проверяются на тестовой базе. См. [HTTP-сервисы 1С](https://v8.1c.ru/platforma/http-servisy/).

## TickTick

1. Зарегистрировать приложение в [кабинете TickTick](https://developer.ticktick.com/manage) под аккаунтом владельца.
2. Добавить адрес возврата `https://nlmo-api.vercel.app/functions/v1/ticktick/callback`.
3. Добавить в секреты Edge Functions рабочего проекта `TICKTICK_CLIENT_ID`, `TICKTICK_CLIENT_SECRET` и `TICKTICK_TOKEN_KEY`. Последний — отдельное случайное 32-байтовое значение в hex. Секреты хранятся в настройках сервера.
4. Применить миграции, развернуть функцию `ticktick` с проверкой доступа внутри функции (`verify_jwt = false`) и собрать сайт. Плановый запуск использует имеющиеся `functions_url` и `hook_secret` проекта.
5. Войти в рабочий кабинет, открыть «Настройки → TickTick», подтвердить доступ на чтение и выбрать рабочие списки. В «Задачи → Из TickTick» проверяются активные и недавние завершённые задачи, обновление и отключение. Данные аккаунта доступны только его владельцу на сайте.

Плановая проверка задач проходит примерно раз в 15 минут для каждого подключённого аккаунта. При временной ошибке сохраняется последняя полная выборка. Если доступ отозван в TickTick, сотрудник может подключить аккаунт заново. [Open API TickTick](https://developer.ticktick.com/docs/index.html#/openapi)
