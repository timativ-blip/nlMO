# Обновление координаторов округов

Имена координаторов в «Команда → Округа» и карточке округа читаются из актуального листа «свод 22-28 июня» таблицы партийных групп. Раньше эти экраны использовали только сохранённый справочник, поэтому замена имени в Google-таблице не отражалась на сайте.

Новый лёгкий запрос `media-groups?view=directory` читает только CSV со справочником. Он не ждёт анализа ВК и Telegram. На сервере источник перечитывается раз в минуту, параллельные обращения используют один запрос. Клиент обновляет справочник при открытии раздела, возвращении во вкладку и раз в минуту, пока она видима. Прежний полный анализ групп сохраняет свой маршрут и кеш 15 минут.

Из строк с объединённым номером округа собирается одно имя. Региональная строка МО исключается; разные имена внутри одного округа требуют уточнения и не выбираются произвольно. Если поле координатора очищено в таблице, старое сохранённое имя его не подменяет.

Имена из таблицы — справочная информация. Уже назначенная учётная запись координатора имеет приоритет: изменение публичной таблицы не меняет чужое имя, роли, права или привязку аккаунта. При недоступности таблицы показаны сохранённые сведения с соответствующей подписью. Сервер может отдать помеченный `stale` кеш не старше 15 минут; затем возвращает 502. На клиенте последнее имя остаётся с явным предупреждением об источнике.

2 ноября 2026 года проверено, что во всех семи строках 121-го округа указан Петухов Тимофей. В рабочей карточке исправлено только сохранённое поле `coordinatorName`, при отсутствии связанной учётной записи; остальные данные и права не менялись. Начальный справочник также исправлен.

Для установки нужны четыре файла `media-groups/index.ts`, `media-groups/directory.ts`, `_shared/district-directory.ts`, `_shared/media-timeline.ts`. Разворачивать перед клиентом, с прежним `verify_jwt=false` (источник уже публичный). Новых секретов и миграций нет. `npm run test:media` проверяет разбор, очистку/конфликт имён, приоритет учётной записи, обновление кеша и отказы источника.

Форма создания встречи теперь явно сообщает о названии длиной 3–120 символов и выделяет слишком короткий ввод. Ограничение уже существовало на сервере; изменено его отображение в интерфейсе. Заголовок из двух символов, например «оо», оставляет кнопку неактивной с пояснением.
