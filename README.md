# Командный центр | Московская область

Внутреннее веб-приложение команды: задачи, календарь, команды округов, отчёты, аналитика и рейтинг в одном месте. Информация вводится один раз: подтверждённая задача сама попадает в недельный отчёт округа, в показатели и в рейтинг.

- **Сайт:** https://timativ-blip.github.io/nlMO/ — GitHub Pages (бесплатно, работает круглосуточно), собирается автоматически при каждом изменении в `main`.
- **База и вход:** Supabase, проект `timativ-blip's Project` (бесплатный тариф, Ирландия).
- **Уведомления:** колокольчик в приложении + Telegram-бот.
- **Демо:** добавьте `?demo` к адресу сайта — откроется демонстрация на вымышленных данных (хранится только в браузере).

## Первый запуск

1. Откройте сайт → «Первый запуск» → создайте учётную запись руководителя (один раз).
2. «Команда» → «Добавить человека»: координаторы и участники. Каждому выдаётся логин (почта) и временный пароль — передайте лично, писем система не рассылает. Списком — через «Настройки → Импорт CSV/XLSX» (после импорта скачайте файл с паролями).
3. Telegram-бот:
   1. в Telegram откройте @BotFather → `/newbot`, получите токен;
   2. [Supabase → Edge Functions → Secrets](https://supabase.com/dashboard/project/wlqwwhshqrqanapsnsik/functions/secrets) → добавьте секрет `TELEGRAM_BOT_TOKEN`;
   3. в приложении: «Настройки → Telegram-бот → Подключить бота»;
   4. сотрудники подключаются сами: «Профиль → Подключить Telegram».

## Как устроено

```
src/
  data/types.ts     сущности: пользователи, округа, задачи, мероприятия, отчёты, показатели
  data/perm.ts      правила доступа по ролям (на сервере продублированы RLS и триггерами)
  data/store.ts     действия приложения; в рабочем режиме изменения уходят в Supabase
  data/backend.ts   синхронизация с Supabase, файлы, серверные функции
  data/calc.ts      все расчёты: план, «вовремя», просрочки, рейтинг, отчёт — с записями-источниками
  data/seed.ts      демо-данные
  pages/            экраны; Auth.tsx — вход и первый запуск; TeamAdmin.tsx — учётные записи
supabase/
  migrations/       схема БД, права (RLS), правила переходов статусов, журнал, напоминания 9:00 МСК
  functions/team-admin   создание учётных записей и сброс паролей (без почты)
  functions/telegram     бот: привязка чата, отправка уведомлений, подключение вебхука
```

Сервер не доверяет клиенту: участник не может сам подтвердить задачу, поменять срок, роль или чужой комментарий — это проверяют триггеры в базе. Каждое изменение задач, мероприятий, отчётов и профилей пишется в журнал (`audit_log`), последние записи видит руководитель в настройках.

## Разработка

```bash
npm install
npm run dev        # http://localhost:5180 — подключается к рабочей базе из .env.local
npm run build
```

Без файла `.env.local` / `.env.production` приложение работает в деморежиме.

## Ограничения бесплатного тарифа Supabase

- 500 МБ базы и 1 ГБ файлов; фото сжимаются автоматически, файлы — до 10 МБ.
- Проект засыпает после 7 дней без единого запроса — при ежедневной работе команды этого не случится.
- Автоматических резервных копий нет: раз в неделю скачивайте копию («Настройки → Скачать резервную копию»).
- Серверы находятся в ЕС (Ирландия); согласуйте хранение персональных данных с ответственным за них в отделении.
